# 📝 ManagerTask

##  Sobre o projeto

O **ManagerTask** é uma API para gerenciamento de tarefas.

O projeto permite que usuários criem, consultem, atualizem e excluam tarefas. Também é possível organizar as tarefas utilizando rótulos.

## Funcionalidades

- Cadastro e gerenciamento de usuários;
- Criação e gerenciamento de tarefas;
- Alteração do status das tarefas;
- Criação e gerenciamento de rótulos;
- Associação de rótulo as tarefas.

## Objetivo

O projeto foi desenvolvido como atividade acadêmica para obetenção da nota parcial na matéria de Desenvolvimento de Software Visual, o trabalho possui C#, banco de dados e operações CRUD.

## Como executar

```bash
dotnet restore
dotnet ef database update
dotnet run
```

Após executar o projeto, a API estará disponível no endereço informado pelo terminal.
